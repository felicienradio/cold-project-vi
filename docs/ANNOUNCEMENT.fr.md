## Julia's Launcher 0.3.25 est sortie 🔧

**Correctifs**
🔧 Le lanceur vérifie maintenant à l'ouverture que **l'émulateur correspond à sa version**, pour que les correctifs du moteur arrivent vraiment sur tous les PC.
📋 Les rapports d'erreur incluent une liste du dossier du jeu (noms et tailles seulement), pour repérer vite un paquet du jeu incomplet. Le jeu se ferme encore une seconde après l'ouverture ? Appuie sur **Send errors** pour qu'on compare.

**Installation**
🔄 En 0.3.x : rien à faire, elle s'installe toute seule dans les 5 minutes, jeu fermé.
📥 Nouveau ou sur un ancien launcher : télécharge **VI-Setup-0.3.25.exe** sur https://github.com/felicienradio/cold-project-vi/releases/latest et lance-le.
